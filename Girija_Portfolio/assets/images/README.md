# Images Directory (`assets/images/`)

Place your project screenshots and profile photographs in this directory.

### Recommended Files:

1. **Profile Picture**:
   - Save your photo here as `profile.jpg` or `profile.png`.
   - In `index.html` (under `.avatar-large`), replace the `GS` text with:
     ```html
     <img src="assets/images/profile.jpg" alt="Girija S" style="width: 100%; height: 100%; object-fit: cover; border-radius: inherit;" />
     ```

2. **Project 1 Screenshot (GiftTrack)**:
   - Save your screenshot (e.g. from `C:\Users\Girija S\OneDrive\Pictures\Screenshots\Screenshot 2026-10-24 105709.png`) as `gifttrack-preview.png`.
   - In `script.js` or in the project card markup, you can reference `assets/images/gifttrack-preview.png`.

3. **Project 2 Screenshot (CineBook)**:
   - Save your screenshot (e.g. from `C:\Users\Girija S\OneDrive\Pictures\Screenshots\Screenshot 2026-10-24 105755.png`) as `cinebook-preview.png`.
   - In `script.js` or in the project card markup, you can reference `assets/images/cinebook-preview.png`.
